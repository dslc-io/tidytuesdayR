# last_tuesday errors with bad dates

    Code
      last_tuesday("blue")
    Condition <tidytuesdayR-error-invalid_date>
      Error in `last_tuesday()`:
      ! "blue" cannot be coerced to a <Date>.

---

    Code
      last_tuesday(1)
    Condition <tidytuesdayR-error-invalid_date>
      Error in `last_tuesday()`:
      ! 1 cannot be coerced to a <Date>.
