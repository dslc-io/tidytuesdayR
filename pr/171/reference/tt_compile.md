# Get TidyTuesday readme and list of files and HTML based on the date

Get TidyTuesday readme and list of files and HTML based on the date

## Usage

``` r
tt_compile(date, auth = gh::gh_token())
```

## Arguments

- date:

  date of TidyTuesday of interest

- auth:

  A GitHub token. See
  [`gh::gh_token()`](https://gh.r-lib.org/reference/gh_token.html) for
  more details.
